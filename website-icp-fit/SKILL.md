# Website ICP-Fit Auditor

Start with the page URL, copy, screenshot or source, the intended buyer, and the action the visitor should take. Identify the entry channel when available. If a URL is inaccessible, ask for the hero, CTA and relevant next step. If the buyer is unknown, report what the page actually says and ask whom it should reach before judging fit.

## Walk the buyer's path

1. Record the surface inspected. A screenshot supports visual observations within its viewport. Plain text supports wording. Source may reveal form requirements. Keep other devices, steps and runtime behavior unassessed unless observed.
2. Read the hero as a buyer arriving from the supplied channel. Quote the words that identify the audience, outcome and alternative. A five-second expert read is a hypothesis about comprehension. Use participant responses for an actual comprehension test.
3. Follow the intended action as far as the evidence allows. Link each friction point to a buyer question, objection or missing piece of proof. Consider source quality, form errors or traffic mix as competing explanations before attributing conversion to copy.
4. Prioritize a change by the importance of the blocked task, the strength of the evidence and implementation effort. Supply replacement copy grounded in the offer. Flag any factual claims that need confirmation.

## Return a page audit

For the most important findings, show location and quote, buyer implication, proposed change and how to test it. End with one change to try first, the eligible audience and success event. If baseline data exist, give the counts and window. Keep predicted lift unquantified unless there is a defensible estimate.

**Worked example.** A procurement lead looking for an implementation plan follows a partner referral. The only supplied hero CTA says “Get started.” Try “See the implementation steps” if such a section exists. Ask a matching buyer to locate the plan and explain the next step. A higher click rate alone cannot establish that more qualified buyers completed the journey.

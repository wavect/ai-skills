# Message match from channel to CTA

Record the promise the visitor saw before arrival, the page headline and the first offered action. For a buyer comparing an existing workflow, identify what changes, for whom and what evidence makes the difference credible. For a buyer newly aware of the problem, start from the situation they recognize.

Quote the exact line that needs work. For “Built for modern teams,” ask which team, doing what, under which constraint. If the brief establishes a finance team's multi-entity close, try copy using those facts. Leave unsupported time savings out of the draft.
